========================================================================
PapaLabel 스마트 라벨 프린터 - Windows 배포판 가이드 (v1.2.1)
========================================================================

1. 프로그램 실행
   - 'client_flutter.exe' 또는 'PapaLabel_실행.bat'을 더블 클릭하여 실행합니다.

2. 즐겨찾기(자주 출력하는 품목) 기능 안내 [신규]
   - 카테고리 탭에 [⭐ 즐겨찾기] 항목이 추가되었습니다.
   - 제품 카드 우측 상단의 별(☆/★) 아이콘 또는 우측 상세 정보 패널의 즐겨찾기 버튼을 클릭하여 자주 인쇄하는 제품을 원클릭으로 등록/해제할 수 있습니다.
   - [⭐ 즐겨찾기] 탭을 선택하면 등록된 품목들만 모아서 빠르게 출력할 수 있으며, 앱을 재실행해도 즐겨찾기 목록이 영구 보존됩니다.

3. 프린터 연결 설정 (블루투스 / USB 선택 지원)
   - 프로그램 상단 탭에서 [설정] 메뉴로 이동합니다.
   - [프린터 연결 설정 (Windows)] 카드에서 [USB 연결] 또는 [블루투스 연결] 중 사용할 방식을 선택합니다.
   - [USB 연결 선택 시]:
     1) PC에 USB 케이블로 연결된 프린터(예: TSC DA220)를 드롭다운에서 선택합니다.
     2) 'USB 프린터 직접 인쇄 사용' 스위치가 켜져 있는지 확인합니다.
   - [블루투스 연결 선택 시]:
     1) 윈도우 [설정 > Bluetooth 및 장치]에서 블루투스 라벨 프린터를 먼저 페어링합니다.
        (카드 내 [Windows Bluetooth 설정 열기] 버튼으로 바로 이동 가능)
     2) 드롭다운 목록에서 페어링된 블루투스 프린터를 선택합니다.
     3) '블루투스 프린터 직접 인쇄 사용' 스위치가 켜져 있는지 확인합니다.
   - [테스트 인쇄] 버튼을 눌러 라벨이 정상 출력되는지 확인합니다.
   - 설정 완료 후 [라벨 인쇄] 및 [피자소스 관리] 탭에서 대화상자 없이 즉시 인쇄됩니다.

4. 라벨 규격 커스텀 설정 방법 (Windows 지원)
   - [설정] 메뉴의 [라벨 규격 설정] 카드에서 원하는 규격을 자유롭게 지정할 수 있습니다.
   - 빠른 규격 선택:
     55x20mm(표준), 50x30mm, 55x30mm, 60x40mm, 80x50mm, 100x60mm 등 프리셋을 원클릭 적용
   - 직접 mm 입력:
     가로 및 세로 길이를 소수점 단위(mm)로 직접 입력 후 [적용] 버튼 클릭
   - 설정 변경 시 라벨 인쇄 탭의 실시간 미리보기 및 인쇄 출력 규격에 즉시 반영됩니다.

5. 부팅 시 자동 실행 등록 방법
   - 일반 시작프로그램 등록:
     '윈도우_시작프로그램_등록.bat'을 더블 클릭하여 실행합니다.
   - 관리자 권한 서비스 형태 자동 등록:
     '윈도우_서비스_자동실행_등록.bat'을 마우스 우클릭 -> [관리자 권한으로 실행]합니다.
   - 해제 시에는 각각의 '해제.bat' 파일을 실행하시면 됩니다.

6. 주의 사항
   - 프로그램 폴더 내의 DLL 파일 및 'data' 폴더는 프로그램 구동에 필수적인 파일이므로 삭제하거나 위치를 변경하지 마십시오.
   - 포터블(Portable) 형태로 제작되어 별도의 설치 과정 없이 원하는 폴더(예: C:\PapaLabel)에 압축을 풀고 바로 사용할 수 있습니다.
