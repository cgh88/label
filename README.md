# 소비기한 라벨관리 프로그램

AI 기반 소비기한 자동 분석 및 라벨 출력 프로그램

## 기능

- AI로 제품 사진 분석
- 소비기한 자동 인식 및 추출
- 카테고리별 라벨 자동 분류
- 맞춤형 라벨 출력 및 인쇄
- 통계 대시보드 및 분석 차트

## 사용법

1. `index.html` 실행
2. 사진 업로드 또는 촬영
3. AI 분석 및 카테고리 선택
4. 라벨 출력 및 인쇄

## 기술 스택

- HTML, CSS, JavaScript
- Tailwind CSS
- Google Gemini API
- jsPDF
- Chart.js
